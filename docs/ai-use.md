# AI use and data provenance

ASTRA's source code, interface copy, and initial architecture were developed with AI assistance. The generated code was then reviewed and exercised locally. The login page displays a NASA/Joel Kowsky Artemis I liftoff photograph, credited and linked to NASA's image article. No AI-generated photo, audio, or video is included.

All four demonstration astronaut profiles, baseline values, time-series readings, radiation values, simulation scenarios, and Isolation Forest training/held-out evaluation rows are synthetic and generated by code. They are labeled `SIMULATED` in the application and database. The research assistant catalog contains short locally authored summaries with links to the original sources; those summaries are not NASA datasets or official NASA guidance.

The model score indicates statistical novelty within synthetic reference data. It is not a medical probability, diagnosis, or validated risk score. Launch-phase rehearsal values are synthetic examples and do not represent a vehicle-specific flight profile, validated limits, or launch clearance. NASA-STD-3001 describes trendable environmental and suit measurements; ASTRA does not convert the standard into universal limits.

The optional LLM provider is off by default. Configure credentials only in the server-side `.env` file; never place a provider key in frontend code or source control. Rotate any key pasted into chat or other shared text before use. A backend topic gate refuses off-topic prompts before storing them or calling a provider. If configured, only a health-related current question and authorized retrieved context are sent to the endpoint. The gate and system instruction constrain behavior; they do not train or fine-tune the model.

No NASA logo, flag, or mission insignia is included. Image credit and source: NASA/Joel Kowsky, [Artemis I Launch](https://www.nasa.gov/image-article/artemis-i-launch-3/).

# AI use and data provenance

ASTRA's source code, interface copy, and initial architecture were developed with AI assistance. The generated code was then reviewed and exercised locally. No AI-generated photo, audio, video, or NASA visual asset is included.

All four demonstration astronaut profiles, baseline values, time-series readings, radiation values, simulation scenarios, and Isolation Forest training/held-out evaluation rows are synthetic and generated by code. They are labeled `SIMULATED` in the application and database. The research assistant catalog contains short locally authored summaries with links to the original sources; those summaries are not NASA datasets or official NASA guidance.

The model score indicates statistical novelty within synthetic reference data. It is not a medical probability, diagnosis, or validated risk score. The optional LLM provider is off by default. If configured, only the current question and authorized retrieved context are sent to the configured endpoint.

No NASA logo, flag, mission insignia, or NASA-branded design element was generated or copied into ASTRA.
